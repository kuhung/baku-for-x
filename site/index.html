核心机制

围绕「少误拦、快纠错、零干扰」设计的过滤流程

单条优先判定

公共服务默认针对单条推文判定；同一账号连续命中多条或经多名用户反馈复核后，才进入共享黑名单，防止普通账号被偶发发言连坐。

无痕隐藏与折叠提示

默认从评论区与引用内容开始扫描并直接隐藏水帖。连续收起 5 条及以上回复时，在原地留一行折叠提示方便临时切遮罩核对。

单条放行与账号信任分离

点「放行」只恢复当前推文并记住豁免，不直接把作者加入白名单；点「信任账号」才恢复该作者全部内容并写入本机白名单。

隐私与运行方式

三种运行模式自由切换，代码全量开源

仅调整浏览器本地显示

扩展只修改当前 X 网页的显示状态，不会读取或改动你的 X 登录状态、关注列表与原生屏蔽列表。开启共享飞轮时仅发送扫描范围内且未命中本机名单的推文结构化字段，服务端限流仅用加盐 SHA-256 哈希后的 IP 摘要，不存原始 IP。

支持纯本机模式、BYOK 与自建 Worker

不希望待判别推文离开本机时，可在管理台关闭共享飞轮切换为纯本机黑白名单与手动屏蔽模式；有需要也可以填入自有接口地址和保存在本地浏览器的 API Key 直连判别，或使用仓库自带的 Cloudflare Worker 独立部署。

FAQ

常见问题

静貘（Baku）是按账号整号封杀，还是按单条推文判定？

日常判定默认落在单条推文上，避免普通账号因为一两条发言被整号误拦。只有同一账号连续命中多条或被多名用户屏蔽并通过复核后，才会进入共享黑名单。

遇到误拦或者漏拦的水帖怎么处理？

遇到漏拦的水帖，点击推文操作栏里的静貘图标即可收起该条并选择撤销或拉黑作者。遇到误拦时，可在弹窗最近拦截、管理台或遮罩条点放行只恢复当前这一条，或点信任账号将作者写入本机白名单。

会改动我的 X 关注列表、原生拉黑名单或上传隐私数据吗？

不会改动 X 登录状态、关注列表或原生屏蔽列表，所有隐藏与遮罩只在当前浏览器标签页显示。开启默认共享飞轮时仅发送扫描范围内未命中本机名单的推文字段，服务端限流仅使用加盐哈希后的 IP 摘要。也可在管理台关闭共享服务，改用纯本机黑白名单或自建 Cloudflare Worker。
