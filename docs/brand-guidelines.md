## 一、命名由来与品牌定位

- **中文名称**：静貘
- **英文名称**：Baku
- **组合写法**：静貘 · Baku（[Chrome 应用商店](https://chromewebstore.google.com/detail/baku-%E9%9D%99%E8%B2%98-for-x/dkcjdiemeobepaahioaakahjijoigoad)名 `Baku for X Slop`，工具栏提示名 `Baku`）
- **动物意象**：结合东方传说里在夜里悄悄吃掉噩梦与杂念的食梦貘，以及天然呈黑白两色的马来貘（Malayan Tapir）。「静貘」谐音「静默」，对应「熊猫吃短信」式的克制脾气：不弹警告条、不打扰视线，安静吃掉 X 时间线与评论区里的水帖，只留下真正在说话的人。
- **双语核心口号**：
  - 中文主口号：吞掉水帖，还你清净
  - 中文说明语：静默清理 X 时间线与评论区里的 Slop
  - 英文主口号：Quietly clear X slop. Keep the real conversation.
  - 英文简版：Quiet slop filter for X.

## 二、视觉标志与图标规范

主视觉以高对比度的宣纸白马来貘大比例侧面特写头像（向左侧望）置于深玄墨底色之上，提取微弯长吻、立耳、安睡闭眼与斜向肩颈负空间线条，保证缩小至 `16px ~ 28px` 工具栏与顶栏图标尺寸时轮廓依然一眼可辨；长吻前方点缀一枚霁青四角星，象征将噪杂水帖静静化作零星微光收走。

### 2. 使用约束

- 图标外部保持透明通道与完整圆角，不在深色背景下额外套厚白框；在玄墨底宣传图中使用极细浅线描微弱分离边界即可。
- 静态主图标不在内部叠加字母、文字或 X 图形；工具栏动态计数仅在左上纯黑安全区绘制无框亮霁青像素数字，不接触马来貘轮廓。
- 工具栏小尺寸（16px 与 32px）默认不叠加 Chrome 原生右下角数字贴片，避免大块色块遮挡马来貘肩背轮廓并制造焦虑感；仅在命中活跃态点亮鼻尖霁青星光，并在图标左上纯黑安全区用像素级无框亮霁青数字（`#53E5CE`，32px 显示 `1–99` / `99+`，16px 显示 `1–9` / `+`）静默报数，0% 遮挡马来貘轮廓。管理台保留「工具栏图标提示」开关以按需切回原生右下角标或纯静默图标。

### 3. 五阶段伴侣演化规范（Popup 与管理台顶栏）

以本机去重后的 `stats.filteredCount` 驱动陪伴形态演进（阶段只升不降，不设数值焦虑与惩罚掉级）；工具栏 `16px / 32px` 图标与推文操作栏 `19px` 触发按钮维持经典一致形态，保障肌肉记忆与小尺寸识别率。

| 阶段 | 名称 | 累计阈值 | 视觉与姿态特征 |
|---|---|---|---|
| 1 | 幼貘 · Fawn | `0 – 9` | 蜷卧幼年马来貘，深玄墨体表带极简宣纸白幼斑与白边圆耳，鼻尖一颗微星 |
| 2 | 寻貘 · Scout | `10 – 99` | 幼斑褪净、白鞍背初现，四足迈步且长吻前探嗅闻，鼻前悬浮清晰星芒与微风细线 |
| 3 | 静貘 · Baku | `100 – 499` | 经典成年黑白马来貘安坐闭目，完整宽大宣纸白鞍背，鼻前单颗霁青四角星配清风弧 |
| 4 | 禅貘 · Sage | `500 – 2,499` | 体态丰腴端坐，肩背云纹初起，霁青梦境丝带环绕长吻与肩侧并点缀三颗星芒 |
| 5 | 栖星 · Astral | `2,500+` | 端坐于极简玄墨与霁青祥云底座之上，身披飘带，背后环绕圆相星环与星尘群 |

- **暗色模式衬底**：五阶段立绘忠实保留真实马来貘玄墨色头部与四肢，因此在 Popup 深色模式下，`.baku-companion` 槽位固定采用低眩光暖灰宣纸底衬（`oklch(88% 0.008 85)`），同时保住墨黑轮廓、暖宣纸白鞍背与霁青星纹的清晰对比。
- **克制进阶反馈**：Popup 统计槽底部仅设 `2px` 高霁青细进度线与单行阶段文字，跨入新阶段后首次打开 Popup 时轻闪一次星光并静默提示，不往 X 宿主页面弹窗。

### 3. 工具栏计数与 X 页面注入色值

- **工具栏左上星光计数（默认）**：在左上纯黑安全区直接绘制无框亮霁青数字 `#53E5CE`（11.7:1 对比度），同步点亮鼻尖星光。

- **X 网页内注入控件**：完整贴合宿主页面自带的浅色（Light）、暗蓝（Dim）与纯黑（Lights out）三种主题，仅将键盘焦点环与吞噬星光统一为静貘霁青（浅色 `#1D6F63`，深色 `#5EC2B2`）。

## 四、界面克制准则

1. **安静默认**：在 X 时间线与评论区命中的水帖默认直接无痕隐藏，工具栏通过鼻尖星光点亮与左上角纯黑安全区无框亮霁青数字静默报数，悬停提示本页拦截条数。
2. **一击吞帖，轻盈联动**：推文操作栏不再放置文字按钮与强制二级弹窗，改用 19px 静貘剪影互动入口；悬浮睁眼警觉，左键单击直接播放吞噬微动画并收起单条水帖，底部 Toast 伴随咀嚼小静貘提供「拉黑 @作者」与「撤销」，右键或 Shift+左键仍可展开完整菜单；Popup 弹窗右侧配备可点击摸头的静貘伙伴。
3. **顶栏三分与信息降噪**：管理台顶栏按「左品牌身份 · 中分段导航 · 右统计与状态」三分对齐；日常健康状态仅用 6px 霁青小圆点配无框文字呈现，不抢占导航与主内容视觉权重，仅在连接异常时使用柔朱砂提示条提醒。
4. **克制留白**：弹窗保持 `360px` 紧凑宽度，仅保留品牌、静默状态点与总开关、本页/累计两组计数（含小静貘伙伴）、最多 3 条最近拦截快审以及「打开管理台」入口。
5. **无干扰账本风**：管理台采用无阴影单线描边卡片（`1px` 边界）与等宽数字计数，交互态提供原地撤销与 5 秒可逆提示。

## 五、文案与命名边界

- 对外品牌统一使用 **静貘 · Baku**（英文语境简写 `Baku`），推文内嵌触发按钮默认使用 19px 静貘剪影图标（无资源环境时极简回退文字 `Slop`），避免撑宽宿主操作栏。
- 已上线部署的服务域名（`anti-slop-flywheel.kuhung.workers.dev`）、D1 数据库名（`anti-slop-db`）及浏览器本地存储键前缀（`antislop_*`）作为底层工程标识保持不变，实现平滑无损升级。
- 对外页面与商店描述遵守克制事实原则：只陈述已实现能力，不写死上游模型型号与内部配额阈值，不用全角破折号、表情符号和营销感叹句。
