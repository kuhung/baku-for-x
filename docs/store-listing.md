## 一、简体中文（`zh_CN`）

### 简短描述（62 字，Chrome 限 132 字符以内）

```text
把 X (Twitter) 评论区的 AI 回复哥、蓝标废话和引流垃圾安静清掉。装上即跑，无痕隐藏，一键吞帖随时放行，开源免费。
```

### 详细说明

```text
刷一条讨论度高的 X 帖子，点开评论区，前排往往塞满蓝标账号的复制式捧场、AI 生成的空洞总结、模板化评论引流和加密空投广告。一条条手动屏蔽跟不上刷新的速度，纯靠关键词过滤也拦不住不断换说法的 AI 水帖。

Baku for X Slop 负责把这批噪音安静收走，把空间留给真正在说话的人。

为什么装上就能清净
不需要导入复杂的规则列表，也不需要自己先申请接口密钥，装好扩展打开 X 就能直接运行。扩展默认重点扫描评论区与引用内容，识别并收起常见的水帖、机器捧场和垃圾推广；如果你习惯连关注流一起清理，也可以在管理台一键切换到全部时间线。日常以单条帖子为单位判定，同一账号屡次命中后才会进入共享黑名单，保护正常博主其余有价值的发言。

安静消失，不制造新的噪音
很多屏蔽脚本会在页面上留下一排刺眼的提示灰条，越刷越分散注意力。Baku 默认把命中的水帖直接无痕隐藏，只在浏览器右上角静貘图标的左上角亮起一枚霁青星光与无框小数字，静默报数。如果你想确认拦掉了什么，随时可以在管理台切换到毛玻璃遮罩模式，逐条展开查看原文。

点一下就吞掉，随时可以反悔
遇到漏网的水帖，单击推文底部操作栏里的静貘小图标，单条水帖当场播放吞噬动画并收起；底部提示条同步给出「拉黑账号」与「撤销」，右键图标或按住 Shift 点击还能展开更多选项。万一遇到误拦，点开弹窗「最近拦截」或遮罩条上的「放行」「信任账号」，原帖会立刻恢复，该账号也会直接写入你的本机白名单。

一点克制的陪伴
打开扩展弹窗可以查看本页拦截数和累计拦截数，弹窗里的静貘会随着你本机的累计拦截进度，从「幼貘」逐步成长为「寻貘」「静貘」「禅貘」「栖星」五个阶段。阶段只升不降，没有打卡和数值焦虑，安安静静守着你的浏览体验。

把隐私和控制权交回给你
如果你平时只看主帖从不翻评论区，保持原样即可。如果你认真逛 X、受够了在海量水帖里翻找人类观点，装上 Baku 就能立刻感受到区别。

所有隐藏与遮罩只改写你当前浏览器的页面显示，你的 X 登录状态、关注列表和原生屏蔽列表原封不动。扩展默认连接公共共享服务开箱即用；你也可以在管理台随时关闭共享服务、切换成纯本机黑白名单并支持 JSON 导入导出，或者填入自建服务端地址与自有模型接口密钥由浏览器直连判别。本项目基于 MIT 协议完整开源，代码公开可查。

现在添加到浏览器，打开 X，清净一下。
```
