## 一、简体中文（`zh_CN`）

### 简短描述（74 字，Chrome 限 132 字符以内）

```text
在 X (Twitter) 网页端过滤评论区与时间线里的 AI 模板回复、水帖和推广引流。安装即用，默认无痕隐藏，支持单条放行、本机名单与开源自建。
```

### 详细说明

```text
Baku for X Slop（静貘）是一款开源 Chrome 扩展，用于在 X (Twitter) 网页端过滤评论区与时间线里的 AI 模板回复、复制式捧场和推广引流帖。

过去在 X 上处理这类水帖主要靠手动拉黑或关键词屏蔽，换一套说法就会漏过。Baku 结合公共黑名单与单条语义判别，把重复的模板回复和推广内容实时收起，减少手动清理的负担。

安装即用，按需切换范围
安装扩展后打开 x.com 即可运行，默认已接入公共判别服务，先从水帖最集中的评论区与引用内容开始扫描。如果关注流里也需要过滤，可以在管理台「云端与模型」把实时判帖扫描范围切到「全部时间线与评论区」。

日常判定默认落在单条帖子上，同一账号连续命中多条或被多名用户屏蔽后，才会经过复核进入共享黑名单。这样既能拦住高频水帖账号，也避免普通账号因为一两条发言被整号误伤。

无痕隐藏与可切换遮罩
命中的帖子默认在页面上直接隐藏，只更新浏览器右上角工具栏图标左上的计数数字与鼻尖星光提示；连续收起 5 条及以上回复时，会在原地留一行可点击的折叠提示，方便临时展开核对。

如果需要逐条查看被拦下的原文，随时可以在管理台把推文处理方式切为「毛玻璃遮罩」，或把工具栏图标提示切回原生右下角标、纯静默图标。

手动屏蔽与放行纠错
遇到漏拦的水帖，单击推文操作栏里的静貘图标即可隐藏当前这一条，底部提示条同步提供「拉黑 @账号」和「撤销」。右键图标或按住 Shift 点击可以展开完整操作菜单，支持只屏蔽单条、拉黑作者，或单独拉黑转帖与引用账号。

遇到误拦时，可在扩展弹窗「最近拦截」、管理台或遮罩条上操作：点「放行」（管理台为「放行此条」）只恢复当前推文并记住豁免，点「信任账号」（管理台为「信任 @账号」）则会恢复该账号全部内容并写入本机白名单。

弹窗统计与管理台
点击工具栏图标打开弹窗，可以切换总开关、查看本页拦截数和累计拦截数，并对最近 3 条拦截记录直接放行或信任。弹窗里的静貘图标会按本机累计拦截条数从「幼貘」到「栖星」依次解锁五个阶段（0 / 10 / 100 / 500 / 2,500），阶段只升不降，并在管理台顶栏同步显示。

打开管理台可以按关键词搜索最近拦截记录，查看生效黑名单、本地拉黑、云端黑名单和信任白名单，并支持导入导出 JSON 备份文件。

隐私说明与运行方式
所有隐藏与遮罩只修改当前浏览器页面的显示，不会改动你的 X 登录状态、关注列表或原生屏蔽列表。

开启默认的共享飞轮服务时，扩展仅发送扫描范围内且未命中本机名单的推文正文、作者 handle、引用及父帖摘要用于判别；主动点击的屏蔽、拉黑与放行会作为匿名反馈信号校准公共名单。服务端限流只使用加盐哈希后的 IP 摘要，不保存原始 IP。

运行方式取舍
如果不希望任何待判别推文离开本机，在管理台「云端与模型」关闭共享飞轮即可，扩展会改为纯本机黑白名单与手动屏蔽模式。有需要也可以填入自有接口地址和 API Key（密钥仅保存在本机浏览器）由浏览器直连判别，或部署自建 Cloudflare Worker 后端。本项目基于 MIT 协议开源，代码公开可查。

添加到 Chrome 后打开 x.com 即可开始使用。
```

### 詳細說明

```text
Baku for X Slop（靜貘）是一款開源 Chrome 擴充功能，用於在 X (Twitter) 網頁端過濾留言區與時間軸裡的 AI 模板回覆、複製式捧場和推廣引流貼文。

過去在 X 上處理這類水文主要靠手動封鎖或關鍵字過濾，換一種說法就會漏掉。Baku 結合公共黑名單與單則語意判別，將重複的模板回覆與推廣內容即時收起，減少手動清理的負擔。

安裝即用，按需切換範圍
安裝擴充功能後打開 x.com 即可運作，預設已接入公共判別服務，先從水文最集中的留言區與引用內容開始掃描。如果追蹤動態裡也需要過濾，可以在管理台「雲端與模型」將即時判貼掃描範圍切換為「全部時間軸與留言區」。

日常判定預設落在單則貼文上，同一帳號連續命中多則或被多名使用者屏蔽後，才會經過複核進入共享黑名單。這樣既能擋住高頻水文帳號，也避免一般帳號因少數發言被整號誤傷。

如果需要逐則查看被擋下的原文，隨時可以在管理台把貼文處理方式切換為「毛玻璃遮罩」，或把工具列圖示提示切回原生右下角標、純靜默圖示。

手動屏蔽與放行糾錯
遇到漏網的水文，按一下貼文操作列裡的靜貘圖示即可隱藏目前這一則，底部提示條同步提供「封鎖 @帳號」和「復原」。右鍵圖示或按住 Shift 點擊可以展開完整操作選單，支援只屏蔽單則、封鎖作者，或單獨封鎖轉貼與引用帳號。

遇到誤擋時，可在擴充功能彈窗「最近攔截」、管理台或遮罩條上操作：點「放行」（管理台為「放行此則」）只恢復目前貼文並記住豁免，點「信任帳號」（管理台為「信任 @帳號」）則會恢復該帳號全部內容並寫入本機白名單。

彈窗統計與管理台
點擊工具列圖示打開彈窗，可以切換總開關、查看本頁攔截數和累計攔截數，並對最近 3 則攔截記錄直接放行或信任。彈窗裡的靜貘圖示會按本機累計攔截則數從「幼貘」到「棲星」依序解鎖五個階段（0 / 10 / 100 / 500 / 2,500），階段只升不降，並在管理台頂欄同步顯示。

打開管理台可以按關鍵字搜尋最近攔截記錄，查看生效黑名單、本機封鎖、雲端黑名單和信任白名單，並支援匯入匯出 JSON 備份檔案。

隱私說明與運作方式

開啟預設的共享飛輪服務時，擴充功能僅發送掃描範圍內且未命中本機名單的貼文內文、作者 handle、引用及父貼摘要用於判別；主動點擊的屏蔽、封鎖與放行會作為匿名回饋訊號校準公共名單。服務端限流只使用加鹽雜湊後的 IP 摘要，不保存原始 IP。
```
